# Python User Management System

A beginner-friendly Python project that demonstrates how to interact with REST APIs using the Requests library.

## Features
- Retrieve users using GET
- Create users using POST
- Update users using PUT
- Partially update users using PATCH
- Delete users using DELETE
- Handle API errors and timeouts
- Menu-driven command-line interface

## Technologies Used
- Python
- Requests Library
- REST APIs
- JSON
- Git and GitHub

## API Used
[JSONPlaceholder](https://jsonplaceholder.typicode.com/)

**Note:** JSONPlaceholder is a testing API. Create, update, and delete operations are simulated and are not permanently stored.

## How to Run

1. Install Python.
2. Install Requests:

   `python -m pip install requests`

3. Run:

   `python user_management_system.py`
